# 📋 Cadastro de Clientes

Aplicação desktop desenvolvida em **Java** durante minha formação em Engenharia de Software.

Projeto acadêmico para praticar **CRUD, interface gráfica e integração com banco de dados**.

### 🛠️ Tecnologias

* ☕ Java
* 🖥️ Java Swing + JTable
* 🗄️ MySQL
* 🔌 JDBC
* 💻 NetBeans

### ✨ Funcionalidades

* ➕ Cadastro de clientes
* 🔎 Consulta de registros
* ✏️ Edição de dados
* 🗑️ Exclusão de registros
* 📊 Exibição dos dados em tabela

📚 **Projeto acadêmico**
